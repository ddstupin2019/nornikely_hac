# Multi-Agent Hypothesis Pipeline 🤖🧠

Мощная система на основе мультиагентной архитектуры для генерации, валидации и ранжирования научных гипотез. Решение использует большие языковые модели (DeepSeek / Qwen), RAG (Retrieval-Augmented Generation) и оптическое распознавание символов (OCR) для анализа проектных файлов, документов, таблиц и картинок.

## 🚀 Особенности
- **Мультиагентная архитектура**: 
  - *Агент 1 (Парсер)* - анализирует ТЗ и извлекает ограничения.
  - *Агент 2 (Генератор)* - генерирует гипотезы на основе базы знаний.
  - *Агент 3 (Критик)* - жестко отсеивает слабые идеи, требуя конкретику, доуточняет названия и механизмы реализации.
  - *Агент 4 (Ранжировщик)* - математически оценивает прошедшие фильтр гипотезы.
  - *Агент 5 (Редактор)* - оформляет финальный результат, подтягивая цитаты и номера страниц из источников.
- **RAG-система (ChromaDB)**: Загружайте PDF, картинки, таблицы. Текст автоматически извлекается (PyMuPDF + Tesseract OCR), разбивается на чанки и векторизуется для поиска.
- **Веб-интерфейс**: Удобный Flask-сервер для загрузки файлов, запуска пайплайна и выгрузки результатов в Markdown (`.md`).
- **Синхронная проверка**: Модели генерируют пулы гипотез, которые прогоняются через циклическую критику.

## 🛠 Установка и Запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.10+ и Tesseract OCR.
```bash
# Клонирование репозитория
git clone <ваш-репозиторий>
cd <папка-проекта>

# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows)
venv\Scripts\activate
# Для Linux/Mac: source venv/bin/activate

# Установка зависимостей
pip install -r my_solution_v1/requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корневой директории и добавьте необходимые API-ключи:
```env
YANDEX_FOLDER_ID=ваш_folder_id
YANDEX_API_KEY=ваш_api_key
```

### 3. Запуск веб-приложения
```bash
python my_solution_v1/main.py
```
Приложение будет доступно по адресу: http://127.0.0.1:5000
