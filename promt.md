Твоя задача написать проект, для решения задачи описаную в task.md.
Решение должно быть сайтом с вэбмордой на основе fastAPi.

Ввод:
1. должно быть ввод задачи (ввиде текста + файлы).
2. Добавить файл в систему rag (научные файлы, учебники).

В решений должны быть реализована система rag для хранения знаний и проверки фактов о металургии,.
Решение состоит из несколькоких агентов все из них реализуюца через api yandex cloud, модель qwen3.6.
Данные для авторизации: api-key берется из окружения, folder: берется из окружения
Все решение должно быть написано в отдельной папке (my_solution_v1), код должен быть написано чисто и понятно с коментариями, так же не забывай про логирование.

Решение:
1. агент принимает на вход запрос пользователя и файлы и стандезирует в формат: (Проблема, Обурудование, бюджет, доп. ограничения)
так же важно выделяет ключевые файлы в отдельную категории к которой обратимся позже.
2. агент получает промт, + ключевые файлы и на основе их делает 10 гипотиз.
3. агент получает гипотезы по очереди. Проверяет на основе rag и ключевых файлов каждую на её реальность и собирает вывод с сылкой на источники. Далее гипотезы, которые корректно отправляем дальше, а не рабочую передаём агенту 2 с доп. промтом что бы он сделал новые гипотизы.
В итоге должны получится 10 гипотез (не более 4 итерации)
4. агент принимает на вход провереные гипотезы и ранжирует их на основе критериев описаных в задаче. далее 5 лучших гипотих со сылками на материал возвращаются пользователю.

Часть rag:
в rag будут хранится картинки, таблички и текстовые данные.
Для картинак и табличак должно быть сделано текстовое описание и по просьбе выдаваться файлы, для этого использую агента
